## Brand & Style

This design system is engineered specifically for streaming and interfacing with targeted desktop Mac windows directly on an Android handset. The visual identity sits at the crossroads of modern macOS precision and tactile, high-utility Android ergonomic design.

Key characteristics:
- **Tone & Persona:** Precise, ultra-focused, utility-first, and low-latency. It minimizes visual distractions so stream frames feel native to the mobile surface.
- **Visual Aesthetic:** Flat Dark UI with crisp, low-contrast boundary strokes. Strictly zero gradients and zero faux-skeuomorphic shadows. Depth is achieved purely through stacked monochromatic surfaces and sharp borders.
- **Interaction Target:** Built around touch ergonomics, respecting Android minimum touch targets (48dp+) while maintaining condensed information density for window session management, stream health indicators, and latency monitoring.

## Colors

The palette uses a midnight-spectrum foundation contrasted with purposeful operational signals:

- **Canvas & Surfaces:**
  - `background` (`#0B0F19` - Abyss): Pure canvas background, reducing OLED power consumption during remote viewing.
  - `surface` (`#141A2A`): Default structural surface for cards, navigation sheets, and window tiles.
  - `surface-elevated` (`#1C243A`): Secondary containers, bottom app bars, popovers, and hovered states.
  - `surface-border` (`#232C45`): 1px structural boundary line across all surface containers.
- **Brand Accents:**
  - `primary` (`#4F46E5`): Used for primary interactive triggers, selections, active segment tabs, and system controls.
  - `primary-hover` (`#6366F1`): Touch feedback and high-priority secondary highlights.
  - `accent-coral` (`#FF5733`): Reserved strictly for live streams, recording states, active broadcasts, and critical remote connect actions.
- **Telemetry & Status:**
  - `status-online` (`#10B981`): Mac discovery, local zero-latency connection.
  - `status-offline` (`#94A3B8`): Standby, disconnected, or asleep state.
  - `status-warning` (`#F59E0B`): Network latency degradation or relay fallback.
- **Text & Content Contrast:**
  - `text-primary` (`#FFFFFF` / 100%): Window titles, primary commands, and numerical metrics.
  - `text-secondary` (`#94A3B8` / 60% alpha): Subtitles, protocol specs, resolution indicators.
  - `text-muted` (`rgba(255, 255, 255, 0.40)`): Inactive states, metadata timestamps, input hints.

## Typography

The type hierarchy relies on **Plus Jakarta Sans** for its contemporary geometric balance and high legibility at micro scales.

- Use `headline-lg` and `headline-md` exclusively for onboarding screens, connected host selection headers, and empty state canvases.
- Use `title-md` and `title-sm` for active desktop window names, application titles (e.g., Xcode, Terminal, Figma), and modal headers.
- Use `body-md` for connection parameters, IP details, and stream settings.
- Use `label-sm` in all-caps formatting for telemetry tokens, bitrate tags, latency badges, and stream status pills (`LIVE`, `60 FPS`, `P2P`).

## Elevation & Depth

This system eliminates drop shadows and directional lighting in favor of a clean, high-performance **Flat Surface Stacking** model:

- **Level 0 (Canvas):** Background `#0B0F19` with zero borders.
- **Level 1 (Cards & Lists):** Surface `#141A2A` bordered with a continuous `1px solid #232C45`. No box shadows.
- **Level 2 (Overlays & Dialogs):** Elevated surface `#1C243A` bordered with `1px solid #232C45`.
- **Level 3 (Focused / Active Stream Frame):** Surface `#1C243A` with active border transition to `1px solid #4F46E5` (or `#FF5733` during active recording/broadcasting).
- **Separators:** Inset divider lines within cards use `#232C45` at 1px thickness without blurs or skeuomorphic bevels.

## Shapes

The geometric identity balances soft ergonomics with window-like framing:

- **Windows & Cards:** Strict corner radius of `14px` (`rounded-[14px]`). This matches modern desktop window curvature translated cleanly to mobile viewports.
- **Buttons & Action Triggers:** Standardized to `rounded-xl` (12px to 16px) for tactile button clarity.
- **Badges & Status Tags:** Pill-shaped (`rounded-full`) for high scanability against square window thumbnails.
- **Inputs & Sheet Dialogs:** Bottom sheets use `16px` top radii; inner text inputs match button geometry with `rounded-xl`.

## Components

### Buttons
- **Primary:** Background `#4F46E5`, text `#FFFFFF`, radius `rounded-xl`, height 48dp, font `label-lg`. Pressed state transitions to `#6366F1`.
- **Accent (Stream Action):** Background `#FF5733`, text `#FFFFFF`, radius `rounded-xl`, height 48dp, font `label-lg`. Reserved for "Start Stream", "Connect Live", or instant disconnect triggers.
- **Secondary / Ghost:** Surface `#141A2A`, border `1px solid #232C45`, text `#FFFFFF`. Pressed state switches surface to `#1C243A`.

### Window Stream Cards
- Container: Surface `#141A2A`, border `1px solid #232C45`, radius `14px`, padding `16px`.
- Header: App icon (24×24dp), Mac App title in `title-md`, window title subtitle in `body-sm` (`#94A3B8`).
- Window Preview Box: 16:10 or 16:9 inner container, border `1px solid #232C45`, radius `8px`, displaying active screen frame snapshot.
- Footer: Latency metric (`12ms`), connection badge, and stream launch button.

### Chips & Status Indicators
- **Online Pill:** Background `rgba(16, 185, 129, 0.12)`, border `1px solid rgba(16, 185, 129, 0.30)`, dot indicator `#10B981`, label `#10B981` in `label-sm`.
- **Live Stream Pill:** Background `rgba(255, 87, 51, 0.15)`, border `1px solid #FF5733`, dot indicator `#FF5733`, label `#FF5733` in `label-sm`.
- **Host Chip:** Neutral `#1C243A` background, border `1px solid #232C45`, text `#94A3B8`.

### Input Fields
- Container: Height 52dp, background `#141A2A`, border `1px solid #232C45`, radius `rounded-xl`, horizontal padding `16px`.
- Text: Primary `#FFFFFF`, placeholder `#94A3B8` (40% alpha).
- Focus state: Border transitions to `1px solid #4F46E5`.

### Toggle & Switch Controls
- Track: 52×32dp, background `#1C243A`, border `1px solid #232C45`, radius `rounded-full`.
- Active Track: `#4F46E5`, border `#4F46E5`.
- Thumb: 24×24dp solid `#FFFFFF`, centered with 4dp offset.
