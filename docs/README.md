# Docs

The design plans in this folder (`*-plan.md`), `BRIEF.md` and `DEVELOPMENT.md` are the working records of the
original project, Sill by Noah Saffer (https://github.com/Saffsanity/sill), carried over with the rename to
Skopry. Their technical content (protocol, rules, test plans) describes this code. What they say about the
site and domain, accounts, mailboxes, App Store listings, "Noah", dates and PR or issue numbers is the original
project's, not Skopry's.

`upstream-notes/` holds two of the original author's release documents untouched (with the old name), for reference.

Skopry's own changes are in the commit history and in `android/README.md`.
